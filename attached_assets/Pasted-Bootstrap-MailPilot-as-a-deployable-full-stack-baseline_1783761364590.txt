MailPilot required a production-ready implementation spanning Spring Boot backend, React web client, and MV3 Chrome extension with a shared AI engine. This PR establishes that baseline with deployable infrastructure, secure API foundations, and end-to-end channel integration points.

Backend platform (Spring Boot)

Added layered backend structure: controllers, services, repositories, DTOs, entities, config, and global exception handling.
Implemented auth flows (register/login/refresh/logout), user profile endpoints, dashboard stats, and RBAC (USER/ADMIN).
Added Gemini integration path via a reusable PromptService and email-processing endpoint with operation-based prompt orchestration.
Added persistence model + Flyway migrations for users, refresh tokens, prompt/email history, templates, preferences, feedback, usage, and audit logs.
Security and API hardening

Added JWT filter-based auth, BCrypt password handling, CORS config, CSRF strategy for API/web interaction, and request rate limiting.
Added OpenAPI/Swagger support for versioned REST APIs under /api/v1.
Added workflow-level GitHub Actions token permissions hardening.
Web app (React + Vite + TypeScript + Tailwind)

Added routed app shell and core pages (landing, auth, dashboard, history, templates, profile, settings, analytics).
Added auth context + Axios client with bearer token propagation.
Added AI composer UI wired to backend email processing.
Chrome extension (Manifest V3)

Added popup + options UIs, background service worker, content script injection hook for Gmail, and message passing to backend.
Added local offline queue behavior for deferred processing and extension storage integration.
Configured multi-entry build for popup/options assets.
Deployment, CI, and docs

Added Dockerfiles (backend/frontend), root docker-compose.yml, env template, and CI workflow.
Added high-signal docs set: README, architecture, installation, deployment, developer guide, troubleshooting, and roadmap.
Example backend security/API configuration introduced:
